# Security and Responsible Use

## Reporting a vulnerability

Please do not open a public issue for security problems. Use the **Report a vulnerability** button under this repository's **Security** tab, or email iamqasimrazamalik@gmail.com with the subject `voice-cloner security`. You should get a reply within 7 days.

Include the version or commit, how to reproduce it, and what an attacker could do with it.

## Secrets

Voice Cloner needs no API keys. Never commit tokens (for example a Hugging Face token), `.env` files, or private voice recordings to this repository or to a fork.

## Responsible use

Voice cloning can be misused. By using this project you agree to:

- clone only your own voice, or a voice whose owner has given you clear permission;
- never use a cloned voice to impersonate someone, commit fraud, harass, or mislead people about who is speaking;
- label synthetic audio as AI-generated where your platform or local law requires it;
- follow the license of the OmniVoice model and the laws of your country.

Report misuse of this project to the email above.
